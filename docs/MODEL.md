# 模型说明

这个游戏用购买力平价单位做逐年推演。下面这些数字都是玩法假设，不是官方统计，也不能当成某个人的收入或某个学校的学费。

## 教育

- 中国分组参考《中华人民共和国义务教育法》（1986 年建立九年义务教育，2006 年修订）。修订后的法律明确不收学费、杂费：[全国人大公布文本](http://www.npc.gov.cn/zgrdw/npc/xinwen/lfgz/zxfl/2006-06/29/content_350178.htm)。游戏里，2008 年起的中国九年教育不把学识或现金当作入学门槛；交通和用品算在家庭日常开销里，不另扣一次。
- 其他国家都有公共基础教育，但按大致组别降低可及性：资源较稳的一组、资源较紧的一组，以及其余国家。1970 年前和 1990 年前再降低一些。这不是“某国不能上学”，也没有覆盖每个国家的真实学制。
- 高中、职业学校、大学、研究生要先有前置学历，再看准备、现金和名额。落榜只损失申请费，下一年可以再考。夜校、成人基础学历和成人大学是另外的多年路径。
- 成人学习的存在参考联合国教科文组织《成人学习与教育建议书》：[UNESCO](https://www.unesco.org/en/legal-affairs/recommendation-adult-learning-and-education)。印度开放学业参考国家开放学校 [NIOS](https://www.nios.ac.in/)，美国同等学历参考 [GED](https://ged.com/)。游戏没有模拟这些机构的报名规则。

## 关系、债务与世界

- 朋友和伴侣都有名字。分开住会按年降低关系；迁居要选择谁同行，团聚和回国要花钱。
- 分开生活时，现金和住房净值各取一半，投资和经营归持有人，个人债务不转移。孩子随对方生活时，按年支付抚养费，不再重复计入家里的儿童生活费。这是简化规则，不是某个国家的婚姻法。
- 债务每年计息。还不上会留下拖欠，连续拖欠后不能再借。家人援助取决于父母是否在世、家庭积蓄和关系，并且几年才能再开口。
- 人均 GDP 只用来缩放物价。它不是玩家的工资。工资来自求职结果，而且可能被拒绝。
- 世界栏只在有史料或严重危机的年份出现。平静年份不再逐年写同一句新闻。
