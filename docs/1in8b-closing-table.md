## 四、差异化立场声明

- 我们**不抄它的真实统计背书**：它有 WHO/OECD 标注，我们走「游戏估算」明示 + 收入位次 + GDP 折算经济。
- 我们**不做它的"出生地规则吃人"极端化**（如强制童婚）：我们有压力事件但**拒绝始终可行**。
- 我们**承认它的拟人密度更高**（每年 2-3 条 ev、tiny 决策极多）；我们用「年内小事线 + 文化池 + 羡慕事件」覆盖同等密度而不打断节奏。
