## 九个展示界面

| 界面 | 目的 | 主要交互 |
| --- | --- | --- |
| 世界首页 | 认识玩法，选择时代、抽样方式与阅读速度 | 出生、继续、本地历史、数据表、明暗、音乐 |
| 出生登记 | 将随机起点变成具体的人 | 名字、家庭、国家、出生年份、同秒出生者；开始一生 |
| 人生面板 | 持续阅读人生并调整重心 | 暂停、速度、下一年、自动抉择、五种重心、投资、旅行、笔记 |
| 抉择弹窗 | 展示关键转折与可选方向 | 暂停时间，选择后记录数值与生活变化 |
| 投资 · 资产 | 管理现金、基金、债券、股票、不动产与负债 | 买入/卖出、查看行情、买房、买车、保险、借贷 |
| 去旅行 | 把钱换成一段记忆 | 选择目的地与同行者，查看价格和幸福收益 |
| 意外事件 | 让年度不完全可预测 | 随机事件自动记录，部分会要求立即选择 |
| 人生回顾 | 看到选择与经历组成的完整故事 | 重要片刻、旅行足迹、留言、PNG 纪念卡、JSON 记录、重开 |
| 手机版 | 小屏幕完整体验 | 顶部时间控制、身份与状态双卡，投资/旅行弹窗单列 |

## 投资与旅行的设计选择

- **投资不是稳赚**：指数、债券、不动产和单只股票有不同波动；现金不够时生活会自动卖出投资，仍不够才形成负债。市场每年结算，暴跌和繁荣都会写进人生纪录。
- **股票是虚构的**：五家公司、价格与涨跌只服务于玩法，不映射真实证券，也不构成投资建议。
- **旅行有代价**：目的地按当地收入定价，同行者越多总价越高；旅行提升幸福、见识和人际，也会留下足迹与偶发的小意外。
- **选择有重量**：买房有首付和房贷，车和保险有年度支出；负债可以主动偿还，也可能在收入不足时慢慢累积。

## 视觉约定

- 浅灰绿纸面 `#edf1eb`，卡片 `#fafbf6`，深青正文 `#263a3b`。
- 酒红 `#8c2946` 用于新人生、关键选择、当前年份等重点；青绿 `#367b73` 表示已走过的时间与状态。
- 衬线标题表现档案与人生叙事，系统无衬线正文保持阅读清晰。
- 原创 SVG 点阵地图、像素房屋与家庭场景，无外部图片或字体依赖。
- 页面支持深色模式、键盘聚焦、弹窗焦点约束和减少动态效果的系统偏好。

## 存档与时间约定

用户进入游戏后自动逐年推进；暂停、选择和信息弹窗均可让阅读停下来。切换浏览器标签后不补算离开期间的时间。选择记录可序列化，刷新后从相同的人生和随机状态继续。

历史人生只作预览，修改历史留言不会替换当前人生。开始新人生前，如果存在未完成的人生，会明确提示覆盖当前进度。存档存在当前设备的 localStorage，不做云同步。
