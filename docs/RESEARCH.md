# 原站实际体验与 demo 范围

研究对象：[80亿分之1 · 简体中文原站](https://1in8b.life/zh-hans/)，版本 v0.8.72 beta。体验日期：2026-10-29。

## 已跑通的一生

实际在线体验了：首页 → 出生抽签 → 出生登记 → 童年 → 教育 / 工作 / 家庭 / 医疗选择 → 死亡片头 → 完整死亡回顾。

随机人物 Imran Rana，2026 年出生于巴基斯坦信德省农村，男性，家庭第 2 收入分位。小学毕业后从事农业与牧业，与 Iqra 共度 32 年，养育 4 个孩子，见到 3 个孙辈。最终在 2083 年、57 岁时因大肠癌去世。原站最终状态记录 39 次决定，净资产为 −60,496 元（按原站的中国大陆物价体感金额）。

体验使用 Playwright 浏览器操作。为缩短原站约 30 分钟的人生时长，在点击公开快转控制后，进一步调用页面已有时间推进函数，每次约 0.2 个模拟年；读取原站自动推荐并点击公开选择按钮。没有强制修改人物年龄、寿命、死因或死亡结果。没有发帖、付款或发送反馈。这个过程是调试快转体验，不能视作纯手工一小时游玩。

## 观察到的结构

- 首页：巨型衬线标题、浅灰绿底、酒红强调色、点阵世界地图、出生概率条、时代 / 抽样 / 时长设置。
- 出生登记：纸质证书、姓名与家庭叙事、国别数据、同秒出生四人、开始人生。
- 人生页面：身份与状态、像素家庭场景、年度重心、倒序事件记录、家人、同龄人、人生地图与国别数据。
- 抉择：时间暂停的居中弹窗，展示情境、选项、成本和可能后果；部分年龄点还有反思记录。
- 终局：生卒年、死因、学历与职业、家庭、财产、关键片刻、人生回顾与分享入口。

## 投资、旅行与随机事件的深挖

在后续研究的「花钱 · 投资」面板里，实际打开了投资、国内旅行和随机事件：美国角色 30 岁时有 7 类资金去向（存款、债券、混合基金、股票、海外指数、不动产、自行挑股），页面只显示其中可用项；中国 2050 年角色缺少不动产，说明可用性与年代/国家有关。旅行由「国内」和「海外」两个条目组成，价格随当地物价和年代膨胀，再乘同行者系数：独自/朋友/兄弟姊妹 1.0，交往对象 1.5，配偶 1.8，家人为 1 + 0.8×配偶 + 0.5×未成年子女。目的地由国家和年代随机抽取，不是玩家在地图上选择；买不起时可以借钱支付。

研究还记录到：原站会在年度里插入「小小的选择」式随机事件；投资切换有手续费和资本利得税，费率按资产类型和国家不同；股票/债券/海外指数/不动产的年度收益和风险提示各自不同。由于三局都没有在现金充裕时完成大额切换，手续费与税的真实扣款数字没有取得，报告里以页面变量和源码规则标注，未当作实测金额。

这些观察影响了 demo 的设计，但 demo 没有复制原站实现：

- demo 让玩家自己选择旅行目的地，原站是随机抽取；demo 的同行者价格系数做成了伴侣 1.8、家人按人数计算、朋友 1.0。
- demo 使用统一的 0.5% 买卖手续费，没有实现国家资本利得税、海外指数汇率和 7 档资产的全部限制。
- demo 的 5 只股票、市场指数和收益率都是虚构的；原站使用更复杂的历史/国家市场模型。
- demo 的 30 多个随机事件是重新编写的，覆盖校园、工作、诈骗、亲情、健康、市场和旅行，不包含原站真实历史事件库。

## 本项目的实现取舍

保留上述体验顺序，并重新编写视觉、文案、SVG 插画与模拟代码。当前闭环为：随机出生 → 年度推进与随机事件 → 有后果的选择 → 投资/股票/旅行/房产 → 完整一生 → 存档与回顾。

本版覆盖 40 个国家的近似数据、14 个成长年龄节点、30 多个随机事件、16 个旅行目的地和 5 只虚构股票。原站更广泛的统计资料、精细生命表、真实历史事件、完整税率/汇率、在线社区、追思馆等未包含在 demo 中。

原站体验只实际深入了少数角色和当前时代，不能据此声称已穷尽所有国家、时代或分支；上述深挖也明确区分了真实点击、DOM 事件和页面函数快进。
