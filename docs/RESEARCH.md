# 原站实际体验与 demo 范围

研究对象：[80亿分之1 · 简体中文原站](https://1in8b.life/zh-hans/)，版本 v0.8.72 beta。体验日期：2026-10-29。

## 已跑通的一生

实际在线体验了：首页 → 出生抽签 → 出生登记 → 童年 → 教育 / 工作 / 家庭 / 医疗选择 → 死亡片头 → 完整死亡回顾。

随机人物 Imran Rana，2026 年出生于巴基斯坦信德省农村，男性，家庭第 2 收入分位。小学毕业后从事农业与牧业，与 Iqra 共度 32 年，养育 4 个孩子，见到 3 个孙辈。最终在 2083 年、57 岁时因大肠癌去世。原站最终状态记录 39 次决定，净资产为 −60,496 元（按原站的中国大陆物价体感金额）。

体验使用 Playwright 浏览器操作。为缩短原站约 30 分钟的人生时长，在点击公开快转控制后，进一步调用页面已有时间推进函数，每次约 0.2 个模拟年；读取原站自动推荐并点击公开选择按钮。没有强制修改人物年龄、寿命、死因或死亡结果。没有发帖、付款或发送反馈。这个过程是调试快转体验，不能视作纯手工一小时游玩。

## 观察到的结构

- 首页：巨型衬线标题、浅灰绿底、酒红强调色、点阵世界地图、出生概率条、时代 / 抽样 / 时长设置。
- 出生登记：纸质证书、姓名与家庭叙事、国别数据、同秒出生四人、开始人生。
- 人生页面：身份与状态、像素家庭场景、年度重心、倒序事件记录、家人、同龄人、人生地图与国别数据。
- 抉择：时间暂停的居中弹窗，展示情境、选项、成本和可能后果；部分年龄点还有反思记录。
- 终局：生卒年、死因、学历与职业、家庭、财产、关键片刻、人生回顾与分享入口。

## 本项目的实现取舍

保留上述体验顺序，并重新编写视觉、文案、SVG 插画与模拟代码。先完成可运行的闭环：随机出生 → 有后果的选择 → 完整一生 → 存档与回顾。

本版覆盖 40 个国家的近似数据和 14 个成长年龄节点。原站更广泛的统计资料、精细生命表、疾病事件、金融资产、在线社区、追思馆等未包含在 demo 中。

原站体验只实际深入了一位巴基斯坦男性的当前时代人生，不能据此声称已穷尽所有国家、时代或分支。
